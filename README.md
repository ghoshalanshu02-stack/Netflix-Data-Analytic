Netflix Data Analytics Project

Project Overview

This project focuses on analyzing Netflix customer data using Python, SQL Server, and Power BI. The objective is to explore customer behaviour, subscription patterns, revenue, and viewing trends through data analysis and visualization.

Tools & Technologies

- Python
- Jupyter Notebook
- SQL Server (SSMS)
- Microsoft Power BI

Project Workflow

1. Data Cleaning & Exploratory Data Analysis (Python)

- Data inspection
- Handling missing values
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)

2. SQL Data Analysis

- Database creation
- Writing SQL queries
- Customer analysis
- Subscription and revenue analysis

3. Power BI Dashboard

- Total Customers
- Active Customers
- Total Revenue
- Average Watch Hours
- Average Rating
- Subscription Plan Analysis
- Account Status Analysis
- Country-wise Customer Distribution
